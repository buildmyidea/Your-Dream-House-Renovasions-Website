# Website copy reference

The client supplied `index.html` as reference material. Its public copy was extracted and adapted for the original website design. Its markup, layout and CSS are not used in the application.

## Adaptation

| Source material | Use in the new website |
| --- | --- |
| Building better spaces, changing lives; tailored building and renovation solutions | A short Built around you headline and a service-specific introduction |
| Skill, care and craftsmanship; communication, workmanship and lasting results | Reworked approach and service copy |
| Six service descriptions | All six retained, including structural works, individual accessibility needs, full-home renovations and approval conditions |
| Free quote and project discussion calls to action | Request a free quote and relevant enquiry links |
| Project gallery and stage labels | Descriptive project names, stage captions and an expanded photograph gallery |
